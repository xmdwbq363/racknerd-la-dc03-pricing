## 线路与性能：延迟好看，优化没有，晚高峰看运气

第三方测评给出的国内平均延迟是 **164–165ms**，参照物是美西普通线路一般在 180ms 上下，DC-03 属于非优化线路里偏低的一档。到美国本土节点上传下载普遍在 800Mbps 上下，东京约 600Mbps，香港、新加坡 400–600Mbps，三网实测上传下载约 500–600Mbps。

延迟低的原因是三网双向直连，仅此而已：没有 CN2 GIA，也没有 CMI 优化。2026 年 9 月更新的路由数据是这样的：

- **电信**：去程走 163 骨干直连圣何塞，转 twelve99 到洛杉矶；回程 Cogent 在圣何塞对接 163 回国。三网里电信延迟最低。
- **联通**：去程 AS4837 直连圣何塞转 zayo；回程大部分直连。
- **移动**：去程 CMI 直连圣何塞转 zayo；回程 CogentCo 对接移动 CMI，南方移动的回程会绕伦敦再回来。

晚高峰的结论要分两份看，因为两份独立测评测得不一样。一份在 11 月 7 日 23 点的实测记录里，三网都有抖动和丢包，联通方向最严重，广东联通节点代理速度掉到约 156Kbps；另一份测评显示电信部分节点轻微丢包、联通移动基本零丢包。两边方向一致：直连线路延迟漂亮，晚高峰吞吐不稳定，联通和南方移动用户的方差最大。移动用户还有额外的坑，大量节点测速失败，回程绕伦敦这件事对体验影响直接。

## 原生 IP、25 端口与 72 小时换 IP 窗口

IP 质量是 DC-03 区别于同价位机器的地方。多家检测库判定它是美国原生 IP（机房 IP，非住宅），风险评分低、无黑名单记录。解锁情况在测评里有明确记录：TikTok 可解美区，ChatGPT 与 Claude 可访问，Netflix 只解美区自制剧，Disney+ 和 Reddit 无法解锁，**25 端口开放**，可以搭邮件服务。25 端口这条值得单独提，多数低价 VPS 为防垃圾邮件直接把 25 端口封了，想自建邮件的用户在选机房时可以直接把 DC-03 排进候选。

IP 质量有个前提：同段邻居决定你的实际体验。有测评者手上那台 DC-03 的 Google 访问被同段用户搞坏，Gemini 直接不可用，需要走 WARP 或另配 DNS；另一份实测里 TikTok、ChatGPT、Claude、Gemini 全部畅通。同一个机房、不同 IP 段，结果可以完全相反。

补救机制是 **下单 72 小时内可在后台免费换一次 IP**，超过 72 小时付费换，一次几美元。所以拿到机器的第一件事不是装环境，是 ping 一遍、跑一遍流媒体解锁，不满意趁免费窗口换掉。这个窗口期过了再发现问题，就得掏钱。
